README - MercadoFacil starter

Instruções rápidas:
1) Extraia este ZIP para sua pasta de projetos do Android Studio.
2) Abra o projeto no Android Studio e synchronise o Gradle (clique em "Sync Now").
3) Ajuste BASE_URL em RetrofitClient.kt para apontar para sua API.
4) Confirme o applicationId em app/build.gradle se desejar outro pacote.
5) Execute o app em um emulador ou dispositivo.

Observações:
- Para usar mapas, será necessário pedir permissões de localização em runtime antes de abrir a tela do mapa.
- Recomendo adicionar Hilt para gerenciar dependências em produção.
